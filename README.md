# 🩺 Diabetes Prediction System

A machine learning-based web application that predicts the likelihood of diabetes using patient health parameters. The system uses **Logistic Regression** and **Support Vector Machine (SVM)** models and provides an interactive web interface built with Flask.

## 📌 Project Overview

The Diabetes Prediction System takes the following patient parameters as input:

* Glucose
* Blood Pressure
* Insulin
* BMI
* Age

The input data is standardized using a trained scaler and then passed to two machine learning models:

* **Logistic Regression**
* **SVM with RBF Kernel**

The application displays the prediction and diabetes probability generated by both models.

## ⚙️ Installation

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Diabetes-Prediction.git
```

### 2. Open the project folder

```bash
cd Diabetes-Prediction
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**macOS/Linux:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

## ▶️ Run the Application

Start the Flask server:

```bash
python app.py
```

You should see something similar to:

```text
Running on http://127.0.0.1:5000
```

Open the address in your web browser.

## 🤖 Machine Learning Models

### Logistic Regression

Logistic Regression is used as a binary classification algorithm to predict whether diabetes is likely to be present based on the provided health parameters.

### Support Vector Machine

The project also uses an SVM classifier with an **RBF (Radial Basis Function) kernel** to classify the patient data.

The outputs of both models are displayed separately so their predictions and probabilities can be compared.
